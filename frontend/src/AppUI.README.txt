Placez ici votre application bilingue en tant que "AppUI.jsx".

C'est le fichier "droguerie-app.jsx" que vous avez déjà (interface FR/AR, RTL,
circuits vente/achat, tableau de bord, etc.). Deux petites adaptations :

1) Remplacez les lectures/écritures window.storage par les appels ./api.js
   Exemples :
     - au chargement :  const products = await api.products();
     - créer une vente : await api.createSale({ start, date, client_id, taux_tva, lignes });
     - avancer :        await api.advanceSale(id);
     - encaisser :      await api.paySale(id, { montant, mode, date });
   (les noms de champs API utilisent snake_case : prix_vente, total_ttc, num_facture…)

2) Masquez les boutons selon les permissions reçues en props :
     import { can } from "./api";
     {can(perms,"sales.write") && <button>Nouvelle vente</button>}
     {can(perms,"sales.delete") && <button>Supprimer</button>}

Exportez le composant :  export default function AppUI({ session, perms, onLogout, UsersPage }) { ... }
